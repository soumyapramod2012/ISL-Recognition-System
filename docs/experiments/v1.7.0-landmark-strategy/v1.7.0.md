**## 3. Recovery Strategies**



**Three recovery strategies were evaluated:**



**### None**



**No landmark recovery was applied to the degraded landmark sequence.**



**### Linear**



**The established linear interpolation strategy used by the earlier robustness pipeline.**



**### v1.7**



**Adaptive landmark recovery using local motion consistency.**



**The strategy considers:**



**- gap length,**

**- local landmark motion,**

**- velocity direction consistency,**

**- velocity magnitude consistency.**



**### v1.7.1**



**A refined adaptive strategy using landmark-wise motion consistency.**



**It was evaluated as an experimental variant of the v1.7 approach.**

**9. Key Finding**



**The v1.7 and v1.7.1 adaptive strategies produced the same classification accuracy as the established linear interpolation strategy for every tested gap length.**



**Therefore:**



**v1.7 does not demonstrate a measurable accuracy advantage over linear interpolation on the current evaluation dataset.**



**10. Decision**



**Linear interpolation remains the selected landmark-recovery strategy for the production pipeline.**



**The v1.7 and v1.7.1 strategies remain experimental research candidates and are not promoted to the production recovery pipeline.**



**This result is considered a valid negative/neutral experimental finding: the additional adaptive complexity did not provide measurable benefit on the current test set.**

**13. Final Conclusion**



**The v1.7 landmark strategy investigation is complete.**



**The experiment demonstrates that landmark recovery improves robustness compared with using degraded landmarks without recovery. However, the proposed adaptive v1.7 and v1.7.1 strategies do not outperform the existing linear interpolation method on the current evaluation set.**



**Accordingly, the project proceeds with linear interpolation as the selected recovery strategy, while retaining v1.7 adaptive recovery as a documented experimental direction for future investigation.**
