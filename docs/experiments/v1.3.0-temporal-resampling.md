# v1.3.0 — Temporal Resampling Experiment

## Status

**Rejected**

This was an experimental change and is not part of the active
training pipeline.

---

## Objective

Investigate whether replacing the original sequence-generation
strategy with temporal resampling would improve BiLSTM recognition
performance.

The experiment specifically tested whether every video could be
converted to exactly 60 frames using temporal interpolation.

---

## Baseline

The experiment used the **v1.1.0 BiLSTM model** as the baseline.

| Parameter | Value |
|---|---|
| Model | ISL_BiLSTM |
| Parameters | 569,286 |
| Sequence Length | 60 frames |
| Test Accuracy | 52.94% |

The model architecture and training configuration were kept unchanged
so that the effect of sequence preprocessing could be evaluated.

---

## Change

Only the sequence-generation strategy was changed.

### Original v1.1.0 behavior

- Sequences with 60 or more frames:
  - 60 frames selected using `np.linspace()`
- Sequences with fewer than 60 frames:
  - Remaining frames filled using zero-padding

### Experimental v1.3.0 behavior

Every input sequence was temporally resampled to exactly 60 frames
using linear interpolation.

Therefore:

```text
Original:
    Short sequence  → Zero padding
    Long sequence   → Frame selection

Experimental:
    Short sequence  → Temporal resampling
    Long sequence   → Temporal resampling


No changes were made to the BiLSTM architecture.

Performance Difference

Temporal resampling resulted in a decrease of:

29.41 percentage points

in test accuracy compared with the v1.1.0 baseline.

Conclusion

Temporal resampling did not improve recognition performance.

The experiment reduced test accuracy from:

52.94% → 23.53%

Therefore, temporal resampling was rejected for the current
pipeline.

The original v1.1.0 sequence-generation strategy was restored.

Experiment Decision

Decision: REJECTED

The temporal-resampling implementation should not be used in the
current production/training pipeline.

The experiment remains documented as part of the project's model
development history and may be revisited in the future if the dataset,
sequence representation, or model architecture changes.

Lessons Learned

This experiment demonstrated that changing temporal preprocessing can
significantly affect model performance even when the neural network
architecture remains unchanged.

The result suggests that preserving the original temporal structure
through frame selection and zero-padding is currently more effective
for this dataset than temporal interpolation.
