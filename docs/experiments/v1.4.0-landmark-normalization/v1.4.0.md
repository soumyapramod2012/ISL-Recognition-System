# v1.4.0 — Spatial Landmark Normalization

## Status

**Accepted**

v1.4.0 is accepted as the new experimental baseline for the
Indian Sign Language Recognition System.

---

## Objective

Investigate whether spatial normalization of MediaPipe landmark
coordinates can improve BiLSTM recognition performance without
changing the neural network architecture.

---

## Baseline

The v1.1.0 BiLSTM model was used as the baseline.

| Parameter | Value |
|---|---|
| Model | ISL_BiLSTM |
| Parameters | 569,286 |
| Sequence Length | 60 frames |
| Test Accuracy | 52.94% |

---

## Experimental Change

The BiLSTM architecture was kept unchanged.

The sequence generation strategy was also kept unchanged.

The only experimental change was spatial landmark normalization.

For each frame:

1. The midpoint between the left and right shoulders was calculated.
2. The shoulder-to-shoulder distance was used as the scale.
3. Valid pose and hand x/y/z coordinates were centered around the
   shoulder midpoint and divided by the shoulder distance.
4. Pose visibility values were preserved.
5. Missing landmarks represented by zeros were preserved.
6. The original SequenceGenerator was retained.

## Classification Analysis

The test set contained 17 samples.

15 samples were classified correctly and 2 were misclassified.

| Class | Precision | Recall | F1 |
|---|---:|---:|---:|
| 61. Summer | 1.0000 | 1.0000 | 1.0000 |
| 62. Spring | 0.6667 | 1.0000 | 0.8000 |
| 63. Winter | 1.0000 | 0.3333 | 0.5000 |
| 64. Fall | 1.0000 | 1.0000 | 1.0000 |
| 65. Season | 1.0000 | 1.0000 | 1.0000 |
| Ex. Monsoon | 0.7500 | 1.0000 | 0.8571 |

The main remaining weakness is the Winter class.

Two of the three Winter samples were misclassified:

- one as Spring
- one as Ex. Monsoon

Winter recall was therefore 33.33%.

---

## Decision

**ACCEPTED**

Spatial landmark normalization produced a substantial improvement
without increasing model complexity.

The BiLSTM architecture remained at 569,286 parameters.

v1.4.0 therefore becomes the new experimental baseline for future
experiments.

---

## Limitations

The test set contains only 17 samples.

Therefore, each individual prediction represents approximately
5.88 percentage points of test accuracy.

The 88.24% result is promising but should not yet be interpreted as
a robust estimate of real-world generalization.

Further experiments should evaluate whether the improvement remains
stable across additional data and/or repeated validation splits.

---

## Next Research Direction

The primary remaining classification weakness is the Winter class.

Future experiments may investigate the Winter/Spring/Ex. Monsoon
confusion while keeping the v1.4.0 normalization pipeline unchanged.

The exact v1.4.0 experiment should say:

Spatial landmark normalization was applied to valid pose and hand x/y/z coordinates using the shoulder midpoint as the origin and shoulder-to-shoulder distance as the scale. Pose visibility was preserved, and missing landmarks represented by zeros were preserved.

That's the exact method we implemented.
