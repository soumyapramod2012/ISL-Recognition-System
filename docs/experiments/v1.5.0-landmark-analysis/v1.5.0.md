# v1.5.0 — Landmark Quality Analysis and Short-Gap Hand Interpolation

## Experiment

**Version:** v1.5.0  
**Branch:** experiment/v1.5.0-landmark-analysis

### Objective

Investigate missing hand landmarks identified during v1.5.0 landmark quality analysis and determine whether short gaps in hand landmark sequences can be repaired before model training.

### Baseline

The v1.4.0 pipeline used:

Raw landmarks  
→ Spatial landmark normalization  
→ Temporal sequence generation  
→ BiLSTM classification

### v1.5.0 Change

The v1.5.0 pipeline adds short-gap hand landmark interpolation:

Raw landmarks  
→ Short-gap hand landmark interpolation  
→ Spatial landmark normalization  
→ Temporal sequence generation  
→ BiLSTM classification

Only missing hand landmark segments with gaps up to 5 frames are interpolated.

Longer gaps are left unchanged.

## Dataset

Classes: 6

Total valid samples: 85

Training samples: 51

## Landmark Quality Findings

The landmark analysis identified substantial missing hand landmark frames across the six classes.

Pose landmarks had no missing frames in the analyzed samples.

Short sequences were present particularly in Winter, Fall and Ex. Monsoon.

The analysis showed that many missing hand-landmark segments were short enough to be candidates for interpolation.
